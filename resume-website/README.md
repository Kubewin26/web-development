# Winner Kubeyinje — Personal Resume & Portfolio Website

A clean, accessible, semantic, and fully responsive personal portfolio website showcasing my academic background, computational research, and transition into Full-Stack Software Engineering.

---

## 🌐 Project Overview

This website serves as my primary developer resume and showcase portfolio. It bridges my scientific foundations in Microbiology, Public Health, and Genome Sequencing Bioinformatics with modern front-end web architecture.

The project emphasizes:

- Clean, semantic HTML5 structure adhering to WCAG 2.1 AA accessibility standards.
- Custom CSS3 styling using modern layout engines (Flexbox and CSS Grid) without relying on external UI frameworks.
- Fluid mobile responsiveness with zero horizontal overflow on small screens.

---

## 🛠️ Built With

- **HTML5**: Semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`) ensuring an accessible document outline for screen readers and SEO.
- **CSS3**: Custom properties (CSS variables), Flexbox navigation, CSS Grid responsive card layouts, and media queries.
- **SVG**: Scalable vector graphics for high-density, crisp display on all screen resolutions.

---

## 🚀 Key Features

1. **Semantic Hierarchy**: Structured without "div soup" — utilizing native HTML landmarks for screen readers and search engines.
2. **Responsive Design**: Designed mobile-first, ensuring smooth reflow across mobile (320px+), tablet, and desktop viewports.
3. **Smooth Navigation**: Working in-page navigation links connecting the Header, About, Projects, and Contact sections with smooth scrolling.
4. **Accessible Styling**: Meets WCAG 2.1 AA contrast requirements (greater than or equal to 4.5:1), includes descriptive `alt` tags on all images, and provides clear keyboard focus states.
